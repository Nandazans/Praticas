# Support Knowledge Base

Este repositório reúne documentação técnica, procedimentos e guias de troubleshooting utilizados em rotinas de Suporte Técnico (N1 e N2).

## Objetivo
Centralizar conhecimento técnico de forma clara, padronizada e reutilizável, visando:
- Redução de tempo de atendimento
- Padronização de processos
- Facilidade de escalonamento
- Melhoria contínua do suporte

## Conteúdo
- Guias de troubleshooting
- Procedimentos operacionais (SOPs)
- Checklists de atendimento
- Exemplos de gerenciamento de incidentes (ITIL)

## Tecnologias e Ambientes
- Windows
- Redes (DNS, VPN, TCP/IP)
- Atendimento remoto
